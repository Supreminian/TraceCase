# 固定样例说明

这些输入和输出由实现者明确编写，通过规范化后的 SHA-256 精确匹配；不是模型运行结果。修改输入会匹配失败。UTF-8 BOM 和换行差异按输入规范处理。

`normal.md` 显式补全角色、审批状态、阈值下行为、驳回原因和去重范围，补充事实属于样例输入。`original-incomplete.md` 保留最初五条规则，输出必须标注缺失信息，不能从完整样例借用规则。

七份样例供工作流演示和程序测试使用，不属于 20 份对照评测数据。非法 JSON 与 Schema 样例故意失败；其他不完整输入可以通过结构校验，但被阻断问题拦截批准与导出。

V1/V2 在固定模式下返回相同预置内容，不用于声称 Prompt 质量改善、模型覆盖能力或真实延迟/Token 成本。
